# FLOMASTER — Development

Рабочая версия: `C:\Program Files\FLOMASTER\`

## Содержимое папки

| Папка/Файл | Описание |
|-----------|----------|
| `backup/` | Бэкапы предыдущих версий |
| `reference/` | Исходники OCIO конфига ACES 1.2 |
| `FLOMASTER_DOC.docx` | Документация |
| `flomaster.ico` | Иконка |
| `flomaster_logo.png` | Логотип |
