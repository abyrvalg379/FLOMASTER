# FLOMASTER — ROADMAP

> **Контекст (2026-09-28):** v2.3 в проде (Program Files + GitHub Release). FLOMASTER рассматривается
> как инструмент **со студийным потенциалом** — готовим почву: укрепляем ядро и данные,
> не превращая лаунчер в собор. Простота личного тула — не жертва, а ограничение дизайна.
>
> **Правила:** номер версии и факт релиза на GitHub — всегда по решению Максима.
> Любое изменение: сначала `publish\` → смоук `work/test/smoke_flomaster.py` → Program Files после одобрения.
> Версии ниже — рабочие метки плана, финальные номера фиксируем при релизе.

## Гейт решения (после v2.6)

Пилот в студии (внутренний) **или** публичный пуш на студийную аудиторию.
Сигналы пилота формируют v2.8+:

- project/shot-контекст (Project Root → подстановка путей и env)
- env-таблицы на профиль (покрывает `.env`, `OCIO_ACTIVE_VIEWS`, `ARNOLD_OCIO` без хардкода)
- кастомный слот темы поверх 7 курируемых (брендинг студии)

## Вне скоупа (пересматривать только при живом запросе)

Farm-сабмит (Deadline/Tractor) · REST API · Linux/Avalonia (WPF; только при конкретной
студийной необходимости — иначе рерайт всех тем/трея/drag&drop впустую) · плагинная система
(pre-launch hook решается `.bat` в профиле) · полный авто-апдейт с подменой exe ·
fuzzy-поиск по пресетам (их 5–15).
