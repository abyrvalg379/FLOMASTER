## Гейт «пилот vs пуш»

Ждём фидбек пилотных пользователей. Сигналы пилота формируют следующий минорный релиз:

- project/shot-контекст (Project Root → подстановка путей и env)
- env-таблицы на профиль (покрывает `.env`, `OCIO_ACTIVE_VIEWS`, `ARNOLD_OCIO` без хардкода)
- кастомный слот темы поверх 7 курируемых (собственный брендинг)

## Вне скоупа (пересматривать только при живом запросе)

Farm-сабмит (Deadline/Tractor) · REST API · Linux/Avalonia (WPF; только при конкретной
производственной необходимости — иначе рерайт всех тем/трея/drag&drop впустую) · плагинная система
(pre-launch hook решается `.bat` в профиле) · fuzzy-поиск по пресетам (их 5–15).
