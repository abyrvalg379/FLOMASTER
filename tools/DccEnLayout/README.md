# DccEnLayout

Фоновая утилита: автоматически включает английскую раскладку при переходе фокуса
на окна DCC-приложений (Houdini, Maya, mplay). Лечит «в русской раскладке не
работают хоткеи» — Houdini/Maya (Qt) матчат хоткеи по символам, а не по
физическим клавишам.

## Поведение

- Переключились на окно Houdini/Maya → в течение ~секунды раскладка стала EN, хоткеи работают.
- В остальных программах раскладку не трогает.
- Внутри DCC русский включается обычным Alt+Shift и держится, пока не уйдёте из
  окна и не вернётесь (набор кириллицы в заметках не ломается: сторож срабатывает
  только на переходах, а не на каждое нажатие).

## Механика

Три инженерных решения, каждое — результат живой отладки (23.10.2026):

1. **События + опрос.** WinEvent-хуки (`EVENT_SYSTEM_FOREGROUND`,
   `EVENT_OBJECT_FOCUS`) дают мгновенную реакцию, но Windows иногда теряет
   доставку переходов — поэтому дублирующий опрос `GetForegroundWindow` каждые
   400 мс, срабатывающий только на смене окна.
2. **Сообщение — в верхнеуровневое окно.** `WM_INPUTLANGCHANGEREQUEST`
   (wParam=0, lParam=английский HKL из `GetKeyboardLayoutList`) действует на
   top-level окно; дочерним Qt-окнам (hwndFocus) бесполезен.
3. **Задержка + окно стабильности.** Пост в момент события Windows затирает
   восстановлением запомненной раскладки окна. Поэтому: событие → таймер 250 мс →
   пост → проверка `GetKeyboardLayout`; EN считается достигнутым после 3 подряд
   стабильных проверок (~1.5 с), максимум 10 постов на переход.

## Сборка и использование

```powershell
powershell -File build.ps1   # → ..\..\FLOMASTER_CS\Resources\DccEnLayout.exe
```

Штатный `csc` из .NET Framework 4 (есть в любой Windows), C#5, ноль зависимостей,
~9 КБ. Итоговый exe вшит в FLOMASTER как Resource — опция «Auto EN keyboard
layout» в Settings разворачивает его в `%LOCALAPPDATA%\FLOMASTER\`, прописывает
автозапуск (HKCU Run `DccEnLayout`) и стартует. Единственный канал развёртывания
— FLOMASTER (standalone-пакет упразднён 23.10.2026); EnLayoutService при
включении подчищает любые standalone-инсталляции и легаси-HoudiniEnLayout.

CLI утилиты сохранён на будущее: `DccEnLayout.exe [процессы...]` — аргументы
(имена без .exe) переопределяют список по умолчанию
(`houdini houdinifx hindie houdinicore mplay maya`).

Журнал: `dcc_en_layout.log` рядом с exe.
