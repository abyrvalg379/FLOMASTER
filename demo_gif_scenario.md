# Demo GIF — сценарий съёмки (FLOMASTER v2.5)

Цель: один GIF в README (EN+RU), ~15–18 сек, показывает главный цикл: дашборд → запуск с OCIO → маршрутизация проектов → смена тем.
Инструмент: ScreenToGif (запись области экрана). Результат — `docs/demo.gif` в репо, вставка в README первым элементом секции Screenshots.

---

## До записи (подготовка, 5 минут)

1. **Демо-контент, НЕ рабочие пути.** Создай папку типа `D:\demo_projects\` с 2–3 файлами:
   `shot010_lighting.blend`, `texture_hero.spp`, `scene_test.hip`.
   ⚠ В кадре НЕ должно быть личных путей, имён и названий заказчиков — GIF идёт в публичный README.
2. **Пресеты в лаунчере** — короткие чистые имена: «Blender 5.2», «Maya 2025», «Houdini 20.5», «Substance Painter». Если реального Painter/Houdini под рукой нет — пресет может указывать на любой exe, для GIF важен факт маршрутизации (статусная строка), не реальный запуск.
3. **Чистый фон:** на заднем плане — открытый Blender с красивой сценой (турнтейбл KARUSELKA — тоже реклама, но необязательно). Рабочий стол и панель задач — без личного.
4. **Тема на старте:** Blender (оранжевый акцент — совпадает с атмосферой заднего плана).
5. ScreenToGif: Frame Rate 15 fps, записывать курсор, область = весь экран (дашборд фуллскрин).

## Сцены (тайминг от нажатия записи)

| # | Время | Действие | Что видит зритель |
|---|-------|----------|-------------------|
| 1 | 0–2 с | Пауза на Blender, затем **Ctrl+Alt+F** | Оверлей разворачивается на весь экран поверх работы |
| 2 | 2–5 с | Пауза (зритель сканирует 3 колонки) | Дашборд: чипы тем, плитки приложений с иконками, PROJECTS, PROFILES, RECENT |
| 3 | 5–8 с | Плитка приложений: наведение → клик по «Maya 2025» | Запуск; статусная строка внизу подтверждает |
| 4 | 8–11 с | PROJECTS: выбрать корень demo → клик по `texture_hero.spp` | Маршрутизация: статус «… → Painter» (файл открылся тем, кем надо, а не текущим пресетом) |
| 5 | 11–14 с | COLOR CONFIG: клик по 2–3 чипам тем подряд (Blender → Houdini → Maya) | Весь дашборд перекрашивается на лету — фирменная фишка |
| 6 | 14–17 с | **Esc** → дашборд схлопывается, снова виден Blender | Оверлей ушёл, работа не потеряна. Пауза 1 с, стоп |

Итого ~17 сек. Если сцена 4 делает GIF длиннее — режь её первой (маршрутизацию можно показать вторым GIF или скрином).

## После записи (обработка в ScreenToGif)

1. Вырезать кадры простоя в начале/конце (оставить 0.5 с запаса до и после действий).
2. Resize: ширина **1280** (или 1024 — попробуй оба, смотри читаемость чипов).
3. Speed: не ускорять (анимация дашборда должна остаться живой).
4. Экспорт GIF: dithering ON (тёмные темы в GIF без дизеринга дают грязные полосы), попиксельно сравни чипы тем — если разваливаются, подними fps до 18 или ширины обратно.
5. Цель по размеру: **≤ 8 МБ** (лимит GitHub для картинок в README — 10 МБ, запас нужен).

## Что я делаю, когда пришлёшь GIF

- Положу в `docs/demo.gif`, вставлю в README EN+RU (Screenshots, первым элементом, без подписей — канон семьи).
- Если вес больше 8 МБ — прогоню через вторую итерацию оптимизации (палитра/кадры).
- Подготовлю посты для r/vfx, r/Maya, r/houdini (EN, без личных путей и имён).
